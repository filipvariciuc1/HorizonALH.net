# The site says "licensed" but never prints the licence number

Filip took the number off the site on purpose: "it looks too professional and sterile. You can mentioned that we are licensed, sure." Senior care SEO advice usually says to show the number as a trust signal, so a future pass will want to add it back. Do not. The word "licensed" is fine anywhere; the number goes in no copy, no schema and no file in this repo.
