# One page, no page per town or per care service

The site stays a single home page plus the small contact and legal pages. Filip likes the one page ("i kind of like the one page we have now"), and for a 10-bed home the map results run on the Google profile, reviews and a matching phone number far more than on extra pages. So the home page gets a few more true words per care service and a cost and questions block instead.

## Considered Options

- A page per care service (mocked on 11/25/2026, looked fine): rejected for now, can be added later without undoing anything.
- A page per nearby town: rejected. Thin pages that say the same thing with a town name swapped are what Google's spam rules call doorway pages.
